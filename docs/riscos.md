# Riscos

| Risco | Tipo | Mitigação |
|---|---|---|
| Direitos autorais (Bandai Namco e detentores da franquia) sobre jogo, assets e marca | Jurídico | Uso pessoal com cópia legítima; nada protegido no Git; consultar advogado antes de qualquer publicação |
| Expansão MMORPG com IP de terceiros | Jurídico | Decisão separada e posterior |
| BIOS/IPL de console para comparação | Jurídico | Só de console próprio |
| Formatos proprietários sem documentação | Técnico | Experimentos pequenos e reversíveis; nada de importador completo antes de validar |
| Lógica difícil de recuperar do executável | Técnico | Reproduzir comportamento observado e documentar a limitação |
| Diferenças entre versões (PS2, GameCube, Xbox) | Técnico | Registrar a versão de origem de cada dado; comparar versões se necessário |
| Dump incompleto ou modificado | Técnico | Conferir hashes com Redump |
| Binários maliciosos | Segurança | Não executar binários do disco; ferramentas só de código aberto com hash registrado |
| Corrupção do original | Técnico | Somente leitura; hash antes e depois de cada sessão |
| Escopo grande para uma pessoa | Projeto | Fases curtas com critérios objetivos |
